# Sticky Square Loader

A small one-page demo for a sticky animated SVG loader with configurable speed and merge strength.

## Demo

GitHub Pages URL:

https://oneznamov.github.io/sticky-square-loader/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is emitted to `dist/`.

## GitHub Pages

This repo is configured to deploy through GitHub Actions. In the GitHub repository settings, set Pages source to **GitHub Actions**.
